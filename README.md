# Получение уведомлений с помощью telegram
Данный скрипт представляет собой консольное приложение на Python, которое отслеживает статус проверки домашних заданий с использованием API Long Polling Devman и мгновенно отправляет подробные вердикты в Telegram-бот. 

# Как установить
Операционная система: любая, где доступен Python 3 (Windows, macOS, Linux). Используем 'pip' для установки зависимостей (requests, python-dotenv):
```
pip install -r requirements.txt
```
Рекомендуется использовать virtualenv/env для изоляции проекта.

# Примеры запуска скриптов
Утилита позволяет пользователю вводить chat-id в качестве обязательного аргумента командной строки при запуске (узнать свой ID можно через специализированных ботов):
```
python notification.py 705982953
```

# Переменные окружения
Программа использует нестандартные переменные окружения для настройки. Эти переменные не могут быть автоматически обнаружены и должны быть указаны в файле `.env` перед запуском программы.

**DVMN_TOKEN** - персональный токен API Devman (находится в личном кабинете платформы).

**TG_BOT_TOKEN** - токен Telegram-бота.
